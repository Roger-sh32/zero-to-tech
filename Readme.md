# Zero to Tech

从零开始的第一个网页：用 HTML 搭结构，CSS 做样式，JavaScript 加一点交互。

## 项目结构

```
zero-to-tech/
├── index.html   # 页面结构
├── style.css    # 样式
├── script.js    # 点击按钮后的交互
└── Readme.md
```

## 功能

- 居中展示一张卡片，标题为「你好，互联网」
- 点击「点我试试」按钮后，段落文字会变成「你刚刚触发了一段 JavaScript。」

## 如何运行

用浏览器直接打开 `index.html` 即可，无需安装依赖或启动服务器。
